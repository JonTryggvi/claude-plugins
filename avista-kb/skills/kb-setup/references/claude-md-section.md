## Knowledge base (avista-kb plugin)
- When starting work on a plugin, theme or tool repo, or on code on a client site, run the `kb-handoff`
  skill's Step 0: check whether the KB already tracks it (`kb tracked <remote or domain>`). If it does,
  read the handoff before starting (`kb-pickup` for anything you didn't build yourself).
- If the work qualifies and isn't tracked, `kb-handoff` asks once with a picker. Don't ask separately.
  After a yes, update the KB at the end of each session without asking again.
- Never let the KB block the actual task: if the KB isn't cloned or its tree is dirty, say so in one line and carry on.
